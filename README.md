# Tulsa Wears — Handmade Fashion E-Commerce

Tulsa Wears is a modern, cinematic e-commerce platform designed for a premium handmade fashion brand. The website combines editorial-style visuals, immersive interactions, dynamic product management, and a smooth shopping experience to create a digital atelier rather than a traditional online store.

## ✨ Highlights

- 🎨 Premium cinematic and editorial-inspired UI
- 👗 Dynamic handmade fashion product catalog
- 🛍️ Product browsing, product details, bag, and checkout experience
- 🔄 Real-time product synchronization with the Admin Portal
- 🖼️ Cloud-hosted product image delivery using Vercel Blob
- 💫 Interactive 3D-inspired product presentation and animations
- 👔 Interactive “Change Look” / look-builder experience
- 🧵 Categories for different handmade and occasion-based collections
- 💰 Dynamic pricing and product information
- 📱 Responsive experience for modern devices
- 🤖 AI-ready architecture for future fashion and styling features
- 🔐 Integrated administrative management through a separate Admin Portal

## 🏗️ Architecture

The platform is built around two connected systems:

**Customer Website**
→ Product discovery  
→ Product details  
→ Shopping experience  
→ Bag & checkout  
→ Interactive fashion experiences

**Admin Portal**
→ Product management  
→ Product image uploads  
→ Orders  
→ Customers  
→ Reviews & feedback  
→ Coupons  
→ Website customization  
→ Security & audit management

The two systems share the product data layer, allowing products and uploaded images managed from the Admin Portal to appear automatically on the customer-facing website.

The application is designed for production deployment with Vercel and supports cloud-hosted product images through Vercel Blob.

## 🎯 Vision

Tulsa Wears aims to combine traditional handmade fashion with modern digital experiences — creating a website that feels like a digital fashion atelier rather than a conventional e-commerce store.
